## ⚡ Command Reference

```bash
# Setup
./dev-setup.sh local        # Alles einrichten
./dev-setup.sh status       # Status prüfen
./dev-setup.sh reset        # Neustart

# Development
npm run dev:local           # Dev-Server
npm run db:studio           # Datenbank GUI
npm run db:push             # Schema pushen
```
