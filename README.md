# SVV Weimar Volleyball Car-Sharing

Hier ensteht eine kleine Webanwendung zur Kommunikation von Fahrgemeinschaften für Spieltage.

## Spieltage hinzufügen

Das Hinzufügen von Spieltagen kann über das python skript `insert_matchdays.py` erfolgen.
Notwendige vorraussetzungen:

-   installierte pip module
-   Spieltage als CSV-Datei exportiert und unter dem Namen `spielplan.csv` im Hauptverzeichnis hinterlegt.
-   env Datei mit notwendigen Werten für Supabase Zugriff
