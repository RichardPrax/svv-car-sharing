# 📋 Command Reference

## 🚀 Setup (Das Wichtigste)

```bash
./dev-setup.sh local          # Alles einrichten
./dev-setup.sh status         # Status prüfen
./dev-setup.sh reset          # Komplett neu starten
```

## 💻 Entwicklung

```bash
npm run dev:local             # Dev-Server starten
npm run db:studio             # Datenbank GUI
```

## 🔧 Datenbank

```bash
npm run db:push               # Schema zur DB
npm run db:seed               # Testdaten laden
```
